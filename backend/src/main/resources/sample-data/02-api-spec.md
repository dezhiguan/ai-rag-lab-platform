# 短信验证码 API 说明

## POST /api/sms/send-code

发送短信验证码。

请求体示例：

```json
{
  "phone": "13800138000"
}
```

## POST /api/sms/verify-code

校验短信验证码。

请求体示例：

```json
{
  "phone": "13800138000",
  "code": "123456"
}
```

## 错误码

| 错误码 | 说明 |
|--------|------|
| SMS_429 | 发送过于频繁 |
| SMS_400 | 手机号格式错误 |
| SMS_500 | 短信服务商调用失败 |
