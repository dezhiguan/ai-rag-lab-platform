# 短信验证码发送失败排查流程

当用户反馈「收不到验证码」时，按以下步骤排查：

## 1. 检查手机号格式

确认手机号符合国内 11 位规则，排除空格与区号错误。

## 2. 检查频率限制

查询 Redis 中该手机号的发送次数与冷却时间，确认未触发 SMS_429。

## 3. 检查 Redis 缓存

确认 Redis 连接正常，验证码写入与读取 key 是否一致。

## 4. 检查短信服务商返回码

查看服务商 API 响应 body，记录错误码与 message。

## 5. 检查 requestId 日志

在应用日志中按 requestId 检索完整调用链。

## 6. 检查短信账户余额

登录短信平台控制台，确认账户余额与签名模板状态正常。
