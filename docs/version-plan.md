# 版本路线图

## V0 项目骨架版

搭建可运行的前后端项目骨架：健康检查接口、统一响应、全局异常处理、基础前端布局与 Dashboard，集成 PostgreSQL 数据源配置（无业务表）。

## V1 文档导入与分块版

支持文档上传、解析与文本分块，为后续检索与问答提供数据基础。

## V2 Naive RAG 问答版

实现基础的检索增强生成（Naive RAG）问答流程。

## V3 RAG Debug 可观察版

增加检索与生成过程的可观察、可调试能力，便于分析链路问题。

## V4 关键词检索版

在向量检索之外引入关键词检索（如 BM25）能力。

## V5 混合检索版

融合向量检索与关键词检索，支持混合检索策略。

## V6 Reranker 重排版

引入重排序模型，对检索结果进行精排以提升相关性。

## V7 评测中心版

建立 RAG 效果评测体系，支持数据集、指标与对比实验。

## V8 工程化增强版

完善权限、多租户、监控、部署与生产级工程化能力。
